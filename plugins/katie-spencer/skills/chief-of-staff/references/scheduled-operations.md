# Scheduled Operations (CoWork)

When running on a schedule in CoWork, you operate asynchronously — doing prep work before the client's session so everything is waiting when they arrive. This is the ultimate leverage: the client starts their day and the work is already half done.

---

## Daily Briefing (recommended: early morning, before client's work day)

Run the full assessment and produce a daily briefing document saved to Google Drive:

```
# Daily Briefing — [Client Name] — [Date]

## Where Things Stand
- [1-2 sentences on strategic foundation status — any changes or gaps]
- [1-2 sentences on content pipeline status — what's done, what's next]

## Today's Recommendation
[What the Chief of Staff thinks the client should work on today and why.
Be specific. Not "work on content" but "write the Week 3 newsletter —
the brief is ready, topic is [X], and it's due before [date]."]

## Pre-Loaded for You
- [What's been prepared — e.g., "Week 3 newsletter brief is ready to go"]
- [What context is queued — e.g., "Your last call transcript is pulled and sorted"]

## Nudges
- [Things that aren't urgent but should be on the radar]
- [e.g., "IP Bank is thin — next time you have a client win, save the details"]

## Intelligence (if Slack/MCP available)
- [Relevant items from Slack channels, CRM, or other integrations]
- [Industry news, competitor moves, audience signals]
```

Post to the client's preferred channel (Slack DM, Google Doc, or Claude conversation) so it's the first thing they see.

---

## Weekly Strategy Review (recommended: Sunday evening or Monday morning)

A deeper assessment that looks at:
- Content performance signals (what got highlighted, shared, replied to)
- Framework cycle coverage — are we rotating through all elements or stuck?
- CTA rotation adherence — are we actually following the plan?
- IP Bank health — are we drawing from the full library or leaning on the same 2 stories?
- Voice Profile drift — any signs the writing is getting generic?
- Upcoming calendar — what's due this week, what's not started?

Produce a Weekly Review document with specific action items for the week.

---

## Month-End Planning Prep (recommended: 3 days before month end)

Pre-draft the next month's content calendar outline:
- Read the Positioning Framework → determine where the framework cycle picks up
- Read the Belief Shift Bank → identify which shifts to prioritize
- Read the Offer Ecosystem → determine the CTA rotation for the month
- Read recent content → check what's been covered recently to avoid repetition
- Produce a draft 4-week calendar skeleton that the client can react to instead of building from scratch

This turns the monthly planning session from a 60-minute blank-page exercise into a 20-minute refinement conversation.

---

## Post-Publish Analysis (triggered after newsletter approval)

After a newsletter is approved and published:
- Note which framework element and belief shift were covered
- Update the internal tracking of cycle position
- Flag any new IP that emerged (phrases, stories, frameworks named in the piece)
- Suggest adding new IP to the IP Bank
- Queue the repurposer if the client wants social cascade
