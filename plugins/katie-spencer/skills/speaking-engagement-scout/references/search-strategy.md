# Search Strategy

How to search for speaking opportunities using cascading refinement. Each search builds on the previous ones — analyze results after each query and refine the next.

---

## Cascading Refinement Approach

Do not run the same generic query repeatedly. Each search should be informed by what the previous searches found or missed.

### Between Searches, Track:

| Signal                        | Next Action                                    |
|-------------------------------|------------------------------------------------|
| Verified payment found        | Search for similar events on the same platform |
| High-visibility free opportunity | Search for similar platforms or series         |
| Named speaker/bureau/podcast  | Search them directly                           |
| Dead end                      | Never search that pattern again                |

### Time Horizon

Include both the current year AND the next year in search queries. Major conferences book 12-18 months ahead. An 18-month horizon catches opportunities that a 6-month window would miss.

---

## Search Categories

### Category 1 — Paid Opportunities

**Goal:** Find events with verified speaker compensation.

**Query patterns:**
- `[speaker's topics] + "honorarium" OR "paid keynote" + [year] [next year]`
- `speaker bureau + [speaker's expertise area] + speakers`
- `corporate events + "speaker fee" + [speaker's industries]`
- `[industry] conference + "call for speakers" + honorarium + [year]`

**Platforms to search:**

Speaker Bureaus:
- BigSpeak, Washington Speakers Bureau
- All American Entertainment, Women Speakers Association
- GDA Speakers, Eagles Talent
- Steven Barclay Agency, PRH Speakers

Event Platforms:
- eSpeakers, SpeakerHub, Thinkers360
- GigSalad, Innovation Women
- Events in America, 10Times

**Refinement:** If initial searches find promising leads, dig deeper into those platforms or event series. If initial searches find dead ends, pivot to corporate/ERG events or association conferences.

### Category 2 — Visibility Opportunities

**Goal:** Find high-visibility free opportunities worth the speaker's time.

**Query patterns:**
- `podcast + [speaker's topics] + "accepting guests" OR "guest application"`
- `virtual summit + "call for speakers" + [speaker's topics] + [year]`
- `[industry] + "guest expert" OR "featured speaker" + [year]`

**Platforms to search:**

Podcasts (specific-show discovery — each guest spot is a discrete engagement):
- Podchaser, MatchMaker.fm, PodcastGuests.com

Events:
- Virtual summits, LinkedIn Events
- Eventbrite professional development
- Professional association calendars

**Out of scope:** HARO, Featured.com, Qwoted, journalist-source matching services. Those are always-on query-response platforms, not speaking opportunities — exclude them entirely.

**Refinement:** If podcast searches are productive, target specific podcast networks discovered. If summits are productive, search for the organizer's other events.

### Category 3 — Targeted/Niche Opportunities

**Goal:** Find industry-specific and audience-specific events that match the speaker's niche.

**Query patterns:**
- `[speaker's target industry] + conference + speaker + [year]`
- `[target audience] + summit OR retreat + "call for speakers" + [year]`
- `ERG events + [speaker's topics] + [year]`
- `association conference + [speaker's expertise] + [year]`

**Refinement:** Use the most specific terms from the speaker's Project Knowledge — industry names, audience descriptors, topic keywords. This is the most focused search category.

## Search Quality Rules

1. **Do not loop.** If a search returns results very similar to previous searches, move on to a different query pattern.
2. **Capture everything.** Even opportunities that seem like a poor fit should be noted — they will be logged as "Skip" to prevent re-finding.
3. **Note payment evidence.** When a search result mentions fees, honorariums, or "paid," capture the exact language. This feeds the Value Score.
4. **Note audience signals.** When a search result mentions audience size, attendee counts, or download numbers, capture them. This feeds the Audience Match and Value scores.
5. **Check application status.** Note whether calls for speakers are open or closed, and any deadline dates found. Note whether the event recurs annually — that determines Watch vs Skip.
