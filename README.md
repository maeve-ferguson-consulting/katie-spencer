# Katie Spencer — Claude Code Plugin

Claude Code skills for Katie Spencer / Zipline Consulting.

## Install

In the Claude desktop app:

```
/plugin marketplace add github:maeve-ferguson-consulting/katie-spencer
```

Enable "Sync automatically" to receive updates as new skills ship.

## Project Knowledge

Each skill reads from documents you add to your Claude Project. After installing:

1. Add `BRAND.md` to your Project Knowledge (delivered separately by Chad)
2. Add `SERVICES.md` to your Project Knowledge — `build-proposal` creates this on your first run

Skills fall back to an inline setup flow if a required document is missing.

## Updates

Skills update automatically in the background when "Sync automatically" is enabled. No reinstall needed.
